# Spring Boot + Kotlin Blog (Learning Project)

This project is a backend web application built to learn how to use Spring Boot with Kotlin by following the official tutorial from Spring.

It demonstrates how to build a simple blog-style application using Kotlin’s concise syntax and Spring Boot’s powerful backend capabilities.

## Overview

The goal of this project was to understand how Kotlin integrates with Spring Boot to build modern web applications.

The application includes:

- A basic blog system with users and articles
- Server-side rendering using templates
- REST endpoints for fetching data
- Database integration using Spring Data JDBC

This project was made by following this tutorial: https://spring.io/guides/tutorials/spring-boot-kotlin

## What I learnt
- How to create a Spring Boot project using Kotlin
- Kotlin-specific features like:
  - Null safety
  - Data classes
  - Extension functions
- Building REST APIs with @RestController
- Using Spring Data JDBC for database access 
- Template rendering with Mustache 
- Writing tests with JUnit and Mockk in Kotlin 
- Structuring a real-world backend project
